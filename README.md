# AI Research Assistant

AI-powered research assistant capable of summarizing documents and generating contextual answers using LLMs.

## Features
- Research Paper Summarization
- Conversational AI
- Semantic Search
- Context Retrieval
- Document Understanding

## Tech Stack
- LangGraph
- OpenAI API
- Streamlit
- Vector Embeddings
- LangChain

## Future Improvements
- Multi-document Analysis
- Citation Generation
- Voice Interaction
- Research Notes Export
